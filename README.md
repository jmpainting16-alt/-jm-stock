# ระบบจัดการร้านหม่าล่า & บาร์นั่งชิล

เว็บแอปหน้าเดียว (ไฟล์ HTML ไฟล์เดียวจบ) สำหรับจัดการร้าน: แดชบอร์ด, บันทึกยอดขาย,
สต็อกวัตถุดิบ, นับสต็อก, รับของเข้า, เมนู/ต้นทุน, รายงาน และสำรองข้อมูล
ทำงานออฟไลน์ได้ และบันทึกข้อมูลอัตโนมัติในเบราว์เซอร์ (localStorage)

## วิธีใช้แบบง่ายสุด
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome / Edge / Safari) ได้เลย

## วิธีนำขึ้น GitHub + เปิดเป็นเว็บ (GitHub Pages)
1. สร้าง repository ใหม่บน GitHub (เช่นชื่อ `mala-shop`) แล้วตั้งเป็น Public
2. อัปโหลดไฟล์ `index.html` และ `README.md` เข้า repo (ปุ่ม **Add file → Upload files**)
3. ไปที่ **Settings → Pages**
4. ที่ Source เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ จะได้ลิงก์เว็บรูปแบบ `https://<ชื่อผู้ใช้>.github.io/mala-shop/`
   เปิดลิงก์นี้ได้จากมือถือ/แท็บเล็ตที่ร้าน แล้ว bookmark ไว้ใช้งานได้เลย

## ⚠️ เรื่องข้อมูล
- ข้อมูลถูกเก็บใน "เบราว์เซอร์ของเครื่องที่เปิด" แต่ละเครื่อง/แต่ละเบราว์เซอร์แยกกัน
  (การนำขึ้น GitHub เป็นการโฮสต์ "ตัวโปรแกรม" ไม่ได้ซิงก์ข้อมูลข้ามเครื่อง)
- ควรกด **ตั้งค่า → ส่งออกข้อมูล** เก็บไฟล์สำรอง `.json` เป็นประจำ
  และใช้ **นำเข้าข้อมูล** เมื่อย้ายเครื่องหรือกู้คืน

## ข้อมูลตัวอย่าง
มีข้อมูลตัวอย่างร้านหม่าล่าใส่มาให้แล้ว (วัตถุดิบ เมนู และยอดขายย้อนหลัง)
ลบทิ้งหรือรีเซ็ตได้ที่หน้า "ตั้งค่า"
